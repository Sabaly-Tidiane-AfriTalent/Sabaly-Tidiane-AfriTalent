## Description du Projet
AfriTalent est un site vitrine moderne conçu pour mettre en relation les freelances tech africains et les entreprises du continent. La plateforme met en avant les profils, propose des grilles tarifaires claires et intègre une navigation interactive fluide qui s'adapte aux tendances du web de 2026.

## Technologies Utilisées
- **HTML5** (Structure sémantique et accessibilité ARIA)
- **CSS3** (Bento Grid, Custom Properties, Flexbox, Grille CSS)
- **Bootstrap 5** (Système de grille, Navbar, Carousel, Accordion, Modal)
- **JavaScript Vanilla** (Manipulation du DOM, Intersection Observer, LocalStorage)

## Fonctionnalités Principales
1. **Dark/Light Mode :** Toggle persistant via le LocalStorage.
2. **Compteurs Animés :** Statistiques s'incrémentant au défilement (IntersectionObserver).
3. **Filtrage Dynamique :** Catalogue de freelances trié instantanément par catégorie.
4. **Validation de Formulaire :** Validation JavaScript stricte (Regex, longueur de message).
5. **Navbar Dynamique :** Effet shrink et changement d'opacité au scroll.
6. **Bouton Retour en Haut :** Apparition fluide pour remonter la page.
7. **Animations au Scroll :** Effet fade-in sur les sections importantes.
